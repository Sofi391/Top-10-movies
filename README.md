# Movie Rating Web App 🎬

A Flask web application that allows users to search movies/series via an API, rate them, add descriptions, and see their top 10 ranked dynamically. Full CRUD functionality included.

## Features
- Search movies/series through an API
- Add your own rating and description
- Top 10 list ranking dynamically
- Edit or delete entries

## Tech Stack
- Python
- Flask
- Bootstrap
- API integration
- Git for version control

## How to Run
1. Clone the repository: `git clone https://github.com/Sofi391/Top-10-movies`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open your browser at `http://127.0.0.1:5000`

## Learning Outcomes
- Working with Flask routes and templates
- API requests and handling JSON
- CRUD operations with dynamic data
- Ranking and sorting logic
